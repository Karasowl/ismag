# guimarais.com

Personal website for Ismael Guimarais — publicista, músico, pensador.

## Stack

- [Astro](https://astro.build) — Static site generator
- [Tailwind CSS](https://tailwindcss.com) — Utility-first CSS
- [Vercel](https://vercel.com) — Hosting & deployment

## Sections

1. **Marketing & IA** — Artículos sobre marketing digital e inteligencia artificial
2. **Fe** — Teología, reflexiones bíblicas, hermenéutica honesta
3. **Política y Cultura** — Análisis político y cultural
4. **Música** — Canciones, letras, discografía, plataformas
5. **Portafolio** — Proyectos profesionales de branding, web, video
6. **Sobre mí** — Bio y trayectoria
7. **Contacto** — Formas de conectar

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deployed automatically via Vercel on push to `main`.
